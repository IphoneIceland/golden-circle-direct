# Figure clashes — copies of one block that disagree on a number

This file used to list every wording the "fullest version wins" rule overrode. It no longer needs to: staging differences are kept per tour in `overrides`, because a block's hook, point and mic line are allowed to differ when one tour stops somewhere and another drives past.

What is NOT allowed is two copies of the same block disagreeing about a figure. Everything below is a bullet list where one tour carries a number the others do not. Some are harmless — a tour that goes into more depth carries more figures. Some are the real thing: 12.0's Grindavik said "days of warning" where 13.0 said "hours", and only one of those can be true. Read them; do not bulk-apply them.
